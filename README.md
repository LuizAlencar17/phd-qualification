# Qualification Thesis (LaTeX)

This repository contains the LaTeX sources for my PhD qualification document.

## Thesis topic

The work focuses on biodiversity monitoring using camera trap data and studies how multimodal AI can help automate parts of the camera trap workflow.

In particular, it discusses computer vision tasks such as empty image detection and explores research hypotheses around using large language models (LLMs) and CLIP-based fusion strategies to improve the reliability of empty-image filtering as a step toward more accurate downstream analysis.
